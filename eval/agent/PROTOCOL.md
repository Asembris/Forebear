# Frozen protocol

Freeze the case file, this protocol, graph SHA-256, request, depth and case order before running either arm. Targets were purposively selected from the shipped graph to cover different evidence problems across its four product codes. FDA source documents and registry records establish the labels. Prior demo targets are excluded. Shared devices and FDA events can recur across cases. This is a challenge set with known positive controls and ambiguous or incomplete cases.

Run the shipped Phase 2 deterministic investigation checklist and report builder, and the shipped Phase 2 autonomous loop in explicit LLM mode. Give both the same request and depth on separate copies of the same offline store. All reports contain a deterministic conclusion and evidence section. Score that section and the visible combined output, and also examine the model-authored summary and findings alone. Keep incomplete, failed and unattempted cases in the denominator for completion. A fallback is never a completed autonomous report.

Use a single model, the first built-in Phase 2 NVIDIA model, to attribute quality and cost. Use temperature zero, shipped tool limits and result shaping, one in-flight request, four seconds minimum between request starts, a 45-second request timeout and session caps of 180 requests, 216,000 requested output tokens and 1.8 million accounted or reserved total tokens. Count every attempt, including length retries. Reserve UTF-8 prompt bytes plus template allowance and maximum output before admission, then use provider usage when available. Stop the sweep at a rate limit, authorization/credit error, transport failure or budget refusal. No substitute model or simulated run.

- **Critical detection.** The unit is a frozen Class I witness by target, holder and event, with at least one listed product recall ID and correct scope. List partial witness record coverage separately. For graph sections, the holder and ancestry chain must match. For model prose, ID attribution must be explicit or unambiguous across the exposed summary and accepted findings. Report missing signals even when deterministic evidence rescues the combined report. Unresolved edges do not supply mandatory witnesses.
- **Citation accuracy.** Audit frozen printed page/role anchors independently of the verifier. For the structured report and checklist, record which anchors are surfaced correctly, absent, or misrepresented. A conflicting source has two anchors. A printed number is distinct from a supported predicate role. Audit substantive model claims against source or graph evidence as appropriate, including incorrect ID and page attribution and claims the verifier accepts. Omissions and unadjudicated items remain visible.
- **Uncertainty and safety.** Independently review exposed conclusions and findings for unwarranted absence, scope or device-wide reassurance. Record whether the focal uncertainty was disclosed with the correct evidence boundary. Track rejected risky claims separately as near misses. Any blocked critical witness on the intended surface or an exposed unsupported reassurance is a NO-GO pending investigation. Graph counts and verifier acceptance are not ground truth.
- **Investigative value.** Count only specific, source-supported information which is material to the decision or next evidence check and absent from the deterministic report and its checklist findings. For example, correctly identifying why two names refer to one clearance, narrowing recall applicability with FDA product detail, or providing a concrete, justified follow-up. Repeating graph facts or a verification status, renaming findings, or generic follow-up earns no increment. Review errors, proposed actions, and out-of-scope claims alongside potential wins.
- **Operational value.** Retain per-case status, duration including pacing, tools, inference attempts, usage, model errors, and visible and rejected content. Compare paired case latencies, total provider usage and local baseline inference cost. No favorable date, case, threshold or model changes after seeing results. At most one targeted before/after cycle, only if measurements justify it and the same case set can be rerun within a strict cap. Keep the original raw results.

GO requires the hard gate to pass and a material demonstrated gain. A CONDITIONAL GO requires the hard gate to pass within an explicitly bounded operating scope, with a demonstrated gain there. Otherwise recommend NO-GO.
